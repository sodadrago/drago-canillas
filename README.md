# Compatibilidad de canillas · Purificadores Drago

Herramienta pública para que el cliente encuentre qué adaptador necesita su canilla y cómo instalar el purificador Drago (MP40, MP70, MP90).

- `fotos/`: fotos de piezas y esquemas de armado.

Se publica con GitHub Pages y se muestra en https://www.sodadrago.com.ar/instalacionpurificador/
